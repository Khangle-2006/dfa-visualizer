User Guide

What is this app?

This tool visualizes the conversion from an NFA → DFA using the Subset Construction algorithm. You can watch each step of the DFA being built from any NFA you define.

How to define an NFA

Write your NFA definition in the Raw Input tab using this syntax:

# Directives start: q0 ← start state final: q2,q3 ← accepting states (comma-separated) alphabet: a,b ← input symbols # Transitions: from -symbol-> to q0 -a-> q1 q0 -epsilon-> q2 ← epsilon / eps / λ are all accepted q1 -b-> q1 q1 -a-> q2

Step-by-step workflow

1
Define your NFA — type or edit the NFA definition in the text area.
2
Build Graph — click to render the NFA graph and pre-compute all conversion steps.
3
Next Step — advance through each frame of the subset construction one at a time.
4
Auto Play — automatically run all frames. Click again to pause.
5
Reset — go back to frame zero and replay from the beginning.

Interacting with the graph

🖱 Drag nodes

Click and hold any node to drag it. Edges update in real-time as you move nodes around.

🔍 Zoom & Pan

Scroll to zoom in/out. Drag the empty canvas to pan the entire graph.

DFA States

Each DFA node is labeled A, B, C… The small text below shows the corresponding NFA subset, e.g. {q0,q1}.

Example: NFA accepting strings ending in "ab"

start: s0 final: s2 alphabet: a,b s0 -a-> s0 s0 -b-> s0 s0 -a-> s1 s1 -b-> s2

This NFA is non-deterministic because from s0 on input a it can go to either s0 or s1. Subset construction produces an equivalent DFA.

Step Log

The Step Log panel on the left records a history of each frame: which state is being processed, which symbol is being read, and which new DFA state (if any) was created.
