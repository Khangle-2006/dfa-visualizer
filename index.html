User Guide

      
    

    


      

        
What is this app?

        
This tool visualizes the conversion from an NFA → DFA using the Subset Construction algorithm. You can watch each step of the DFA being built step-by-step from any NFA you define.

      


      

        
🖥️ Interface Overview

        

          

            
Left Panel

            
Contains all input controls: Raw Input, Transition Table, and the Guide. Also shows Frame counter, State status, and Step Log.

          

          

            
Right Canvas

            
Two interactive graph panels — Original NFA (top) and Emerging DFA (bottom). Drag the divider between them to resize.

          

        

      


      

        
🔘 Buttons explained

        

          

            
🔨 Build Graph

            
Parses your NFA input and draws the graph. Also pre-computes all subset construction steps. Always click this first after defining or editing your NFA.

          

          

            
⏭ Next Step

            
Advances the DFA construction by one frame. Each frame corresponds to one subset construction action — processing a state, creating a new DFA state, or adding a transition.

          

          

            
▶️ Auto Play

            
Automatically plays through all frames at 750ms per step. Click again to pause. The button pulses blue while playing.

          

          

            
🔄 Reset

            
Clears the DFA canvas and rewinds to frame 0, without changing your NFA input. Useful to replay the animation from the beginning.

          

        

      


      

        
📋 Step Log

        
The Step Log records each action as frames play. Entries include:

        
    
          
  • ▶ Start — initial ε-closure computed for start state
    • 
          
  • ⚙ Processing — a DFA state is being expanded
    • 
          
  • ✦ NEW — a brand-new DFA state was discovered
    • 
          
  • → on 'x' — an existing transition was confirmed
    • 
          
  • ✓ Done — conversion complete
    • 
        

      


      

        
📝 Raw Input — Syntax Guide

        
Write your NFA in plain text. Lines starting with # are comments.

        

          

            
① start: <state>

            
The initial state of the NFA.

            start: q0

          

          

            
② final: <s1>, <s2>, …

            
Accepting states, comma-separated.

            final: q2  or  final: q2, q3

          

          

            
③ alphabet: <s1>, <s2>, …

            
Input symbols (do NOT include epsilon).

            alphabet: a, b

          

          

            
④ Transitions: from -symbol-> to

            
Type a dash - then the symbol then a greater-than > — that's your arrow -a->


            q0 -a-> q1


            For ε-moves: epsilon  eps  λ

            q0 -epsilon-> q1

          

        

        
Full template:

        
# ── Directives ───────────────────
start: q0
final: q2          # multiple: q1, q2
alphabet: a, b     # do NOT include epsilon here

# ── Transitions: from -symbol-> to ──
q0 -a-> q1         # dash + symbol + > makes the arrow
q0 -epsilon-> q2   # epsilon transition (ε-move)
q1 -b-> q1         # self-loop
q1 -a-> q2

      


      

        
📊 Transition Table

        
The Trans. Table tab shows and lets you edit the NFA transitions in table form.

        

          

            
✏️ Edit cells

            
Click any cell — including the State column — to edit it. Type new values like {q1,q2} or Ø for empty.

          

          

            
🔄 Auto-sync

            
Press Enter or click away to apply. The Raw Input textarea updates automatically — then press Build Graph to see the new NFA.

          

          

            
↕ Resize table

            
Drag the bottom edge (the dotted bar below the table) up or down to make the table taller or shorter.

          

          

            
→ / * prefixes

            
→ marks the start state. * marks accepting states. These are display-only — don't type them when editing.

          

        

      


      

        
🖱️ Interacting with graphs

        

          

            
Drag nodes

            
Click and hold any node to drag it anywhere. Edges update in real-time.

          

          

            
Zoom & Pan

            
Scroll to zoom. Drag the empty canvas background to pan.

          

          

            
Resize panels

            
Drag the horizontal divider between the NFA and DFA panels to change their heights.

          

          

            
Graph notation

            
→ start   ⊙ accepting   dashed edge = ε
